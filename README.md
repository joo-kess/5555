# وِرد — مسابقة يوسف ولجين

موقع عربي لمتابعة الصلوات الخمس والتنافس الودي بين يوسف ولجين. يعمل على GitHub Pages، وتتم مزامنة النتائج عبر Firebase.

## النقاط
- كل صلاة مفروضة مسجلة = نقطة.
- إكمال الصلوات الخمس في اليوم يضيف ٥ نقاط مكافأة.
- كل نشاط إضافي متاح (قيام الليل، السنن، النافلة، الضحى، الوتر، أو صلاة إضافية) = ٥ نقاط يوميًا لكل نوع.
- يعرض الموقع إجمالي النقاط، ونتائج الأسبوع (يبدأ الاثنين)، والشهر، والسنة، وسجل النشاط.

## ربط الحسابين بأمان
الموقع يستخدم تسجيل دخول Google. لا تسمح قواعد Firestore إلا بحساب يوسف لتعديل سجل يوسف، وحساب لجين لتعديل سجل لجين. يجب إكمال هذه الخطوات قبل تسجيل نقاط حقيقية:

1. فعّل Google في Firebase Authentication، وأضف `joo-kess.github.io` إلى Authorized domains.
2. افتح الموقع وسجّل دخول يوسف مرة واحدة، ثم خذ UID من Firebase Console → Authentication → Users.
3. اطلب من لجين فتح الموقع وتسجيل الدخول بحساب Google مرة واحدة، وخذ UID الخاص بها من Users.
4. ضع المعرّفين في `firebase-config.js` (`playerUids.yousef` و`playerUids.lujain`).
5. استبدل `SET_YOUSEF_UID` و`SET_LUJAIN_UID` في `firestore.rules` بالـ UIDs نفسيهما، ثم انشر القواعد من Firestore → Rules.
6. ارفع التعديلات إلى فرع `main` في GitHub. GitHub Pages ينشر من جذر الفرع.

إلى أن تُربط الحسابات وتُنشر القواعد، تسجيل الدخول لا يمنح صلاحية تعديل، وقواعد Firestore ترفض الوصول من الحسابات غير المحددة. لا تشارك كلمات المرور أو رموز الدخول؛ المطلوب فقط تسجيل دخول المستخدم بنفسه.

## الملفات
- `index.html`: الواجهة.
- `style.css`: التصميم المتجاوب.
- `app.js`: احتساب النقاط والمزامنة.
- `firebase-config.js`: إعداد تطبيق Firebase ومعرّفا الحسابين.
- `firestore.rules`: قواعد صلاحيات Firestore.
