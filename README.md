# وِرد — مسابقة يوسف ولجين

موقع عربي خفيف لمتابعة الصلوات الخمس يوميًا والتنافس الودي بين يوسف ولجين. التصميم يعمل على الهاتف والكمبيوتر، ويمكن استضافته على GitHub Pages.

## النقاط
- كل واحدة من الصلوات الخمس اليومية = نقطة واحدة.
- إتمام الصلوات الخمس في اليوم يضيف تلقائيًا ٥ نقاط مكافأة.
- كل نشاط إضافي (قيام الليل، السنن الرواتب، النافلة، الضحى، الوتر، أو صلاة إضافية) = ٥ نقاط. كل نوع إضافي يُسجّل مرة في اليوم لكل متسابق.
- الأرصدة الكلية والأسبوعية والشهرية والسنوية تُحسب من سجل النشاط. يبدأ الأسبوع يوم الاثنين.

## المعاينة
افتح `index.html` عبر خادم محلي (مثل إضافة Live Server) لتجربة الموقع. بدون إعداد Firebase تحفظ المعاينة البيانات في المتصفح الحالي فقط، ولا تنتقل لجهاز آخر.

## تفعيل المزامنة على جهازين
GitHub Pages يستضيف ملفات الموقع الثابتة، ويحتاج الموقع إلى قاعدة بيانات مشتركة. إعداد Firebase مرة واحدة يفعّل مزامنة فورية بين يوسف ولجين:

1. أنشئ مشروع Firebase في [Firebase Console](https://console.firebase.google.com/) ثم أضف تطبيق ويب.
2. من Authentication فعّل **Anonymous**.
3. أنشئ قاعدة بيانات Firestore في وضع الإنتاج.
4. استبدل القيم الإرشادية في `firebase-config.js` ببيانات إعداد تطبيقك من Firebase.
5. انشر قواعد `firestore.rules` من تبويب Firestore Rules.
6. ادفع الملفات إلى مستودع GitHub. من **Settings → Pages** اختر فرع `main` والمجلد `/ (root)`.
7. افتح رابط Pages على الجهازين؛ ستظهر التغييرات مباشرة.

Firebase client config مخصص للتعريف بمشروع الويب، وقواعد Firestore هنا تتطلب جلسة Firebase مجهولة وتتحقق من شكل السجلات. الرابط عام، لذلك استخدمه للمسابقة الودية فقط ولا تضع فيه بيانات شخصية.

## الملفات
- `index.html` واجهة الموقع.
- `style.css` التصميم المتجاوب.
- `app.js` النقاط والسجل والمزامنة.
- `firebase-config.js` بيانات ربط مشروع Firebase.
- `firestore.rules` قواعد Firestore.
